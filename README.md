**Sr. Data & AI Engineer** | Building real-time pipelines, RAG systems, and production SaaS

I've spent 10+ years shipping data systems at scale — from 500 TB crypto market pipelines to AI-powered property search to a self-funded SaaS platform. I don't manage tickets; I own outcomes.

### What I've Shipped

- **Trepp** — RAG-powered property search engine (HuggingFace + OpenSearch + LLM) — shipped in 7 months.
- **Rivian** — Built the data platform from scratch. 1,000+ tables, 100+ pipelines, Kafka/Flink streaming.
- **Capital One** — Self-healing Kafka containers, real-time ZeroMQ feeds, Protobuf serialization.
